# Support and contributions

Creator: Cristian2737
Creator page: https://cristian2737.itch.io/

The official release is free. Optional donations support maintenance, requested
features and the creator's other projects. Donations do not unlock features,
buy priority, guarantee an implementation or limit anybody's use of the Bible.

After publication, use the itch.io project's discussion board for support,
bugs and feature requests. A source repository can also accept Issues and pull
requests once its real URL is added to the release page.

For a bug report, include package version, Unity/SDK versions, PC/Quest,
desktop/VR, steps to reproduce, expected behavior and the exact Console error.
Avoid posting private notes, account information or authentication tokens.

For a feature request, explain the reading/study need and how you would use it.
World creators and readers are welcome to suggest changes without donating.

The source is included. Original contributions are CC0; preserve applicable
third-party notices. Do not imply that forks are endorsed by Cristian2737.

An avatar-native arm Bible is a separate future project. This release runs
inside worlds and uses Udon; it does not travel between worlds on an avatar.
