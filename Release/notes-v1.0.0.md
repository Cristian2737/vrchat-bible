First standalone release of Cristian2737's free VRChat KJV Bible.

- Complete offline 66-book KJV with responsive reading and grouped navigation.
- Search, highlights, notes, bookmarks, history and per-world persistence.
- Hand resizing, smooth view/controller following and accessibility settings.
- Shared scripture and delegated study hosting with individual following screens.
- Safe add-to-open-scene installer, reusable prefab and editable source.

Choose the Unity package or VPM zip, not both. Installation instructions and
third-party notices are included. Original contributions are CC0; credit is
appreciated. Donations are optional and never unlock features.

Validated with Unity 2022.3.22f1 / Worlds SDK 3.7.5: independent installations,
ClientSim UI/rejoin checks and local PC/Android SDK builds. Real VR hardware,
live multiplayer and VRChat cloud persistence require in-world playtests.
